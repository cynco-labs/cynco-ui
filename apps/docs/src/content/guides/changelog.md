## 0.1.0

The first release of `@cynco-labs/ui` as its own package.

- **Components:** buttons, inputs, selection controls, overlays, navigation, data display, feedback and form labels on Base UI and Tailwind CSS v4.
- **Layout primitives:** `DataList`, `StatGrid` and `StatTile`, `SectionPanel`, `KeyValueList`, `ActionBar`, `ScrollRow`, `ToneDot`, `Kbd`, `useHotkey` and `DensityProvider`.
- **Productivity:** `JournalGrid`, `AmountInput`, `InlineEditCell`, `CommandPalette`, `ShortcutsDialog`, `SavedViewsBar`, `BulkActionBar`, `UndoToast`, `DensityToggle` and `PrintButton`.
- **Documents:** the document kit and tax invoices, quotations, credit and debit notes, receipts, delivery orders, purchase orders, payment vouchers, statements of account, payslips and six financial reports, with `DocumentStudio`.
- **Accounting:** sales, ledger, banking, reports, expenses and parties, and tax, assets and operations components.
- **AI:** chat, reasoning, tool calls, prompt input and the workflow canvas in `@cynco-labs/ui/ai`.
- **Theme:** light, dark, modern and modern dark; `theme.css` for Tailwind users and a standalone `styles.css`; bundled Inter, JetBrains Mono, Geist and Newsreader.
- **Registry:** `registry/components.json` and a Markdown page per component, used by the `cynco-ui` CLI.
