# CopyTextButton

A bordered mono chip that copies its text, with a copy icon.

```tsx
import { CopyTextButton } from "@cynco-labs/ui";
```

## Usage

```tsx
import { CopyTextButton } from "@cynco-labs/ui";

export default function CopyTextButtonDemo() {
	return <CopyTextButton text="C25718364020">C25718364020</CopyTextButton>;
}
```

## Use

Showing a document number or ID the user is expected to copy.

## Props

`text`, optional `children` (display), `copySize`, `icon`.
